01 / START WITH PEOPLE

화면보다 먼저,
중고 거래를 이해했습니다.

요청은 인증 중고 신규 서비스 UX 설계였습니다. 하지만 바로 화면을 만들지 않았습니다. 사람들이 중고 거래에서 무엇을 불안해하고, 어떤 순간에 안심하는지부터 확인했습니다. 고객의 걱정과 실제 서비스 조건을 맞춰보며 문제를 ‘가격’이 아니라 ‘확인할 수 없는 상태와 책임’으로 다시 정의했습니다.

01.1 / PAIN → TRUST

고객이 걱정하는 지점과
믿는 조건을 나눠봤습니다.

실제 상태, 숨은 하자, 사용 이력, 검수 주체, 배송·설치 이후 책임이 보이지 않을수록 구매는 멈췄습니다. 반대로 같은 기준의 상태 정보, 실제 상품 사진, 책임 주체와 보증이 있을 때 판단이 시작됐습니다.

ANXIETY보이지 않는
상태와 하자

판매자의 설명과 일부 사진만으로 실제 제품을 추측해야 했습니다.

UNCERTAINTY누가 어디까지
책임지는가

검수·배송·설치·A/S 기준이 구매 전 명확하지 않았습니다.

TRUST확인 가능한
근거와 보증

실제 상태, 동일한 기준, 하이마트의 책임이 선택을 만들었습니다.

걱정 수집→신뢰 조건 정의→서비스 역할 재정의→하이마트가 인증하고 관리하는 중고 거래
01.2 / THE ROLE

중고 제품을 파는 서비스가 아니라,
믿을 수 있는 이유를 전달하는 서비스.

결국 핵심 키워드는 신뢰였습니다. 하이마트가 직접 인증하고 관리한다는 사실을 문구로만 알리는 것이 아니라, 상품화 과정과 콘텐츠, 구매 화면 전체에서 반복해서 확인할 수 있게 해야 했습니다.

CORE PRINCIPLE

신뢰를 말하지 않고,
신뢰가 보이는 경험을 만듭니다.

02 / PROOF SYSTEM

신뢰를 약속이 아니라,
확인 가능한 근거로 바꿨습니다.

신뢰는 인증 배지 하나로 완성되지 않았습니다. 고객이 보는 정보와 현장에서 만드는 정보가 같은 기준을 가져야 했습니다. 제품이 입고된 순간부터 검수·세척·촬영·등록·배송·보증까지 하나의 Proof System으로 연결했습니다.

02.1 / PROOF MOMENTS

구매 직전까지 필요한 근거를,
적시적소에 노출했습니다.

상품 리스트에서는 등급과 핵심 상태를, 상세페이지에서는 실제 사진과 하자·검수 정보를, 결제 전에는 배송·설치와 2년 무상 보증을 보여줬습니다. 고객이 다시 의심하는 순간마다 다음 판단에 필요한 정보를 배치해 이탈을 줄였습니다.

01 / CONDITION상태 등급

같은 언어로 비교하고 실제 상태를 이해합니다.

02 / REAL PHOTO실제 상품 사진

대표 이미지와 하자 Detail을 숨김없이 보여줍니다.

03 / PROCESS검수·상품화

하이마트가 직접 확인한 과정을 증명합니다.

04 / CARE2년 무상 보증

구매 이후의 책임 범위까지 안심하고 판단합니다.

입고→검수→세척→촬영→상품화→PDP→배송·설치→2년 무상 보증
02.2 / 16:9 REAL VIEW

사진은 장식이 아니라,
가장 기본적인 신뢰의 증거였습니다.

실제 상품을 매장에서 볼 수 없다면 사진이 대신해야 했습니다. 정면·후면·좌우·상단·하단·하자 Detail을 같은 구도와 조도로 기록하고, 과도한 보정 없이 실제 상태를 전달하도록 촬영 기준을 만들었습니다.

03 / CONTENT & ENVIRONMENT

콘텐츠를 만들기 전에,
콘텐츠가 만들어지는 환경을 설계했습니다.

UX만 좋아져서는 신뢰가 유지되지 않았습니다. 사진과 영상이 만들어지는 현장의 품질이 달라지면 고객이 받는 정보도 달라집니다. 촬영 공간과 장비, 작업 순서, 가이드와 검수 기준을 직접 보고 함께 정리했습니다.

03.1 / STUDIO GUIDE

조도·조명·구도까지,
상품화의 첫 화면을 맞췄습니다.

파주 안심중고 센터의 촬영 동선을 확인하고 스튜디오 세팅을 제안했습니다. 제품 위치와 카메라 높이, 배경과 조명 방향, 필수 컷과 하자 Detail, 보정 원칙을 가이드로 만들어 누구나 같은 품질로 촬영할 수 있게 했습니다.

현장의 기준이
온라인의 신뢰가 되도록.

촬영자마다 다른 감각에 의존하지 않도록 조도·조명·카메라 거리·구도·필수 컷·파일명·업로드 전 QA까지 한 흐름으로 정리했습니다. 직접 촬영하고 편집하며, 기존 중고 플랫폼과 다른 신뢰의 증거가 무엇인지 검증했습니다.

LIGHT조도·조명 방향

재질과 흠집이 과장되거나 가려지지 않도록 설정

FRAME카메라 높이·구도

제품 비율과 상태를 왜곡하지 않는 기준

SHOT LIST필수 컷·하자 Detail

앞·뒤·좌·우와 고객이 궁금해할 영역을 고정

QA보정·업로드 검수

실제보다 좋아 보이게 만드는 편집을 제한

03.2 / AI CONTENT

촬영이 어려운 공정은,
사실을 근거로 다시 보여줬습니다.

상품화 과정의 일부는 작업 환경이나 시간 때문에 직접 재촬영하기 어려웠습니다. 실제 현장 사진·시연 영상·작업 기록을 근거로 콘티를 만들고, AI 이미지와 동영상으로 이해를 돕는 콘텐츠를 직접 제작했습니다. 생성 후에는 사실과 어긋나는 장면이 없는지 다시 검수했습니다.

02 / ANALYSIS

정보 추출

고객이 미리 알아야 할 행동과 조건을 정리

03 / STORYBOARD

콘티 설계

04 / QA

04 / PDP EXPERIENCE

구매를 망설이는 순간마다,
다음 판단을 도왔습니다.

신뢰는 콘텐츠가 예쁘게 보이는 순간보다 구매 직전의 의심을 줄일 때 작동합니다. 어떤 정보가 허들이 되는지 직접 찾고, 상품화 과정·인증·보증을 상세페이지의 실제 의사결정 흐름에 맞춰 배치했습니다.

04.1 / OWNER STORY

중고 거래에도,
사람 사이의 온기를 남겼습니다.

당근처럼 이전 소유자의 경험이 다음 구매자에게 전해지면 제품의 히스토리와 온정이 생깁니다. 이전 소유자가 제품에 대한 코멘트와 홍보 메시지를 남기면 포인트를 지급해 적극적으로 참여하도록 제안했고, 구매자는 그 이야기를 읽은 뒤 선택하도록 했습니다. 아이디어를 실제 PDP에 포함했습니다.

PDP MODULE / PREVIOUS OWNER

제품의 이력까지 알고,
더 안심하고 선택합니다.

누가 얼마나 사용했고 왜 보내는지, 다음 사용자에게 어떤 점을 추천하는지. 이전 소유자의 짧은 메시지가 제품을 낯선 중고품이 아니라 이어지는 생활의 이야기로 바꿉니다.

OWNER NOTE
“매일 우리 가족의 빨래를 맡아주던 제품입니다. 다음 집에서도 오래 쓰이길 바랍니다.”
이전 소유자 코멘트 · 참여 포인트 지급

의심이 생기는 위치에,
하이마트가 확인한 근거를 놓았습니다.

정보를 한 번에 몰아넣지 않고 고객의 질문 순서에 맞춰 배치했습니다. 상태를 볼 때는 등급과 실제 사진을, 결제 전에는 배송·설치와 2년 무상 보증을 확인하도록 했습니다.

05 / SCALE THE STANDARD

대형가전에서 중고 모바일까지,
같은 신뢰의 기준을 확장합니다.

처음은 세탁기·냉장고·건조기·의류관리기·세탁/건조기 같은 대형가전이었습니다. 지금은 중고 모바일까지 범위를 넓히고 있습니다. 카테고리가 달라져도 고객이 안심하는 방식은 달라지지 않도록, 현장 가이드와 상품화 기준을 함께 배포하고 있습니다.

05.1 / MOBILE EXPANSION

매장에서 찍는 순간부터,
온라인에 보이는 순간까지 일관되게.

중고 모바일은 지점별 촬영 환경과 작업 방식의 편차가 컸습니다. 실제 매장에서 촬영할 수 있도록 조명·구도·필수 컷·상태 정보·상품화 순서를 직접 가이드로 만들고 배포해, 어디서 등록해도 같은 품질의 콘텐츠가 보이도록 했습니다.

같은 기준이
다른 카테고리로.

대형가전에서 시작한 신뢰 설계를 모바일의 작은 흠집과 기능 점검, 구성품 확인까지 확장했습니다. UX와 콘텐츠, 촬영 환경과 운영을 하나의 시스템으로 관리합니다.

THE TAKEAWAY

UX만 설계한 것이 아니라,
신뢰가 만들어지고 전달되는 전 과정을 설계했습니다.

리서치에서 시작해 촬영 가이드, 스튜디오 환경, 실제 콘텐츠 제작, AI 콘텐츠 검수, PDP의 구매 전환 설계와 모바일 확장까지. 하이마트가 인증하고 관리하는 믿을 수 있는 중고거래 경험을 일관되게 전달하기 위해 모든 과정에 참여했습니다.
