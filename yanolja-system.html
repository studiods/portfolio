01

화면을 그리기 전에,
누가 어디서 어떻게 쓰는지부터 정의했습니다.

B2B 제품은 실제 근무 조건이 사용성을 좌우하기 때문에 사용자와 환경을 먼저 기준으로 삼았습니다.

01.1 / BEFORE SYSTEM

디자인 시스템을 만들기 전,
항상 네 가지 질문부터 시작했습니다.

기능과 컴포넌트를 바로 정의하지 않고 서비스의 성격, 전달 가치, 실제 사용 환경, 일관된 경험의 조건을 먼저 확인했습니다.

우리 서비스가 가진
성격은 무엇인가?

우리는 어떤 가치를
사용자에게 전달하는가?

사용자는 어떤 환경과 조건에서
서비스를 사용하는가?

통일되고 일관된
사용자·브랜드 경험을 제공할 수 있는가?

SOURCE - 신동식 Portfolio / HST GROUP DESIGN SYSTEM, p.48
01.2 / REAL CONTEXT

사업과 브랜드뿐 아니라,
실사용자의 근무 환경까지 디자인 조건으로 봤습니다.

연령과 업무 패턴, 모니터 크기와 해상도, 조도, 자세처럼 실제 현장에서 정보 인지에 영향을 주는 조건을 함께 검토했습니다.

01 / USER

연령과 역할

실제 근무자의 연령과 업무 역할을 고려해 정보 밀도와 표현 방식을 판단했습니다.

02 / DISPLAY

모니터 환경

화면 크기와 해상도를 기준으로 주요 정보의 우선순위와 시인성을 검토했습니다.

03 / LIGHT

조도와 대비

밝은 환경과 어두운 환경 모두에서 빠르게 상태를 확인할 수 있도록 대비를 고려했습니다.

04 / POSTURE

업무 자세

장시간 화면을 바라보는 현장 업무 특성을 고려해 눈의 피로와 인지 부담을 줄이고자 했습니다.

05 / BEHAVIOR

행동 패턴

빠른 상황 파악과 반복 입력이 많은 업무 흐름에 맞춰 조작과 피드백을 단순화했습니다.

SOURCE - 신동식 Portfolio / HST GROUP DESIGN SYSTEM, p.48

BUSINESS · BRAND+사용자와 실제 근무 환경→공통 UX 원칙과 컴포넌트
02

제작 방향을 명확히 하고,
세 가지 목표로 시스템을 압축했습니다.

직관성, 글로벌 확장성, 제품 간 일관성을 디자인 시스템의 공통 판단 기준으로 잡았습니다.

02.1 / THREE GOALS

빠르게 이해하고, 어디서나 쓰고,
제품이 달라도 같은 경험을 주는 것을 목표로 했습니다.

01 / CLARITY

직관적이고 명확한 형태와 색상

근무자가 빠르게 상황을 파악하고 대응하도록 시인성과 정보 인지성을 높였습니다.

02 / GLOBAL

글로벌 표준을 위한 범용 설계

국가·언어·문화·환경 차이를 고려해 해외에서도 확장 가능한 규칙을 만들었습니다.

03 / CONSISTENCY

일관된 사용성과 브랜드 경험

각 제품이 하나의 경험처럼 이어지도록 공통 요소와 제품 간 연결성을 고려했습니다.

SOURCE - 신동식 Portfolio / HST GROUP DESIGN SYSTEM, p.49
02.2 / TRANSLATE

목표는 추상적인 슬로건이 아니라,
실제 화면에서 판단할 수 있는 규칙으로 바꿨습니다.

빠른 인지, 다양한 환경 대응, 제품 간 동일한 UX라는 기준이 컬러·형태·타이포·컴포넌트 설계에 직접 연결되도록 했습니다.

CLARITY → VISIBILITY

상태와 행동의 우선순위를 색과 대비로 명확히 했습니다.

짧은 시간 안에 상태를 판단해야 하는 B2B 업무 흐름을 기준으로 삼았습니다.

GLOBAL → ACCESSIBILITY

색각과 환경 변화에서도 구분 가능한 방향을 우선했습니다.

Primary Color와 명도·채도 체계를 다양한 조건에서 사용할 수 있도록 설계했습니다.

CONSISTENCY → COMPONENT

반복되는 기능을 같은 규칙과 상태로 통일했습니다.

버튼·입력·선택·날짜 등 공통 패턴이 제품마다 달라지지 않도록 정리했습니다.

03.3 / SHAPE & CONTRAST

버튼의 모서리와 대비도,

RADIUS / ACTION HIERARCHY
