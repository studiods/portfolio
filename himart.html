VOICE → UX POINTS / BEFORE MASTER STRATEGY

우리는 어떤 전략으로 개선된 UX를 사용자들에게 전달할 것인가?

이 단계에서 최종 UX 전략을 확정하지는 않았습니다. 고객이 하이마트에 기대하는 강점과 반복해서 말한 불편을 기준으로, 이후 설계에서 반드시 반영해야 할 포인트를 먼저 정리했습니다.

01 / EXPERTISE

전문성을 24시간 디지털 경험으로

전문 상담과 방문 컨설팅의 신뢰를 AI Agent와 데이터 기반 안내로 확장합니다.

02 / CARE

구매를 케어의 시작으로

설치·A/S에 대한 신뢰를 구매 이후 관리와 중고판매까지 이어지는 관계로 연결합니다.

03 / OMNI

온라인과 매장을 하나의 맥락으로

스마트픽, 단골매장, 매장 혜택과 상담을 온라인 여정 속에서 자연스럽게 이어줍니다.

04 / BASICS + α

검색·탐색의 기본기를 먼저

속도, 동적 필터, 정보 위계와 AI 요약으로 고관여 가전의 탐색 부담을 낮춥니다.

05 / TRANSPARENCY

약속과 상태를 눈에 보이게

주문·결제·배송·설치·케어 상태를 한눈에 보여주고 개인별 관리 정보를 선제적으로 제공합니다.

RESEARCH METHODAI 기반 심층 검색과 다양한 채널의 사용자 목소리를 수집해 유사 키워드를 묶고, 긍정·부정 경험의 반복 패턴을 대표화했습니다. 이 결과는 최종 전략이 아니라 이후 UX 방향을 세우기 위한 고객 관점의 입력값으로 사용했습니다.

AS-IS JOURNEY / WHERE IT BREAKS

데이터를 하나의 여정으로 놓고 보니, 끊기는 위치가 더 명확해졌습니다.

고객은 홈에서 순서대로 이동하지 않았습니다. 외부에서 이벤트·상품으로 바로 들어오기도 하고, 검색과 비교를 반복한 뒤 PDP에 도달했습니다. 이 흐름을 기준으로 실제로 다음 행동이 약해지는 구간을 다시 표시했습니다.

AS-IS에서 확인한 단절을 화면별 과제로 쪼개지 않고 하나의 구매 흐름으로 다시 연결했습니다. 각 단계가 무엇을 보여줄지가 아니라, 고객의 다음 판단을 어디까지 완료시켜야 하는지로 역할을 바꿨습니다.

SUBHOME / CATEGORY

상품 분류보다 구매 목적을 구체화하는 화면

카테고리를 단순 나열하지 않고 사용 상황·공간·가구 형태·설치 조건처럼 실제 구매 판단 기준을 중심으로 탐색 방향을 잡습니다. 고객이 무엇을 사야 하는지보다 어떤 조건의 제품이 필요한지를 먼저 좁힙니다.

품목 중심 분류 → 상황·목적 중심 탐색
SEARCH

검색창이 아니라 니즈를 상품 후보로 바꾸는 도구

추천검색, 가이드, 카테고리별 동적 필터와 AI 요약을 통해 모호한 요구를 실제 상품 후보로 구체화합니다. 검색 결과에 도달하기 전부터 탐색 기준을 제공해 고관여 가전의 학습 비용을 낮춥니다.

추천검색 · 동적 필터 · AI 요약 · 탐색 가이드
SRP / PLP

상품 나열이 아니라 후보를 빠르게 압축하는 비교 화면

대표 가격·혜택·리뷰·설치 조건과 핵심 스펙을 같은 기준으로 비교할 수 있게 하고, 검색에서 사용한 필터와 맥락을 목록까지 유지합니다. 사용자가 다음 화면으로 가기 전에 후보군을 충분히 줄일 수 있어야 합니다.

지속 필터 · 핵심 비교 기준 · 가격/혜택 명확화
PDP

상세 정보를 읽는 곳이 아니라 구매 확신을 완료하는 곳

가격과 혜택, 리뷰, 설치 조건, 매장 실물 확인, 전문 상담과 케어 정보를 하나의 판단 흐름으로 연결합니다. 하이마트가 가진 오프라인 전문성과 설치·A/S 신뢰를 온라인 구매 결정에 직접 사용하게 합니다.

가격 · 설치 · 매장 · 상담 · 케어를 한 번에 판단
CART / PAY

입력 과정이 아니라 최종 조건을 확인하고 확정하는 화면

총 결제금액, 적용 혜택, 배송·설치 조건을 변하지 않는 정보로 명확히 보여주고 구매에 필요한 입력만 남깁니다. 결제 직전 새로운 조건이 등장하거나 앞서 본 혜택을 다시 계산해야 하는 부담을 없앱니다.

총액 고정 · 혜택 확인 · 설치 조건 확정 · 입력 최소화
INSTALL / CARE

구매의 끝이 아니라 관리 관계가 시작되는 화면

설치 일정, 폐가전 회수, 보증, A/S와 케어 상태를 하나의 흐름으로 연결합니다. 구매 이후 언제 무엇이 진행되는지 투명하게 보여주고, 향후 관리와 중고판매까지 이어지는 평생Care 관계의 시작점으로 확장합니다.
