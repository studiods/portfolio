02 / BEHAVIOR DATA

고객의 말이 실제 이용 행동에서는
어떻게 나타나는지 확인했습니다.

2026년 상반기 유입 채널, 세션과 구매전환, Mobile·PC 시작 화면, 검색 사용, 홈 클릭, PDP 이후 행동을 함께 놓고 실제 구매 흐름에서 다음 행동이 약해지는 지점을 확인했습니다.

ENTRY CHANNEL52%

AD 유입이 가장 컸습니다.

Direct 31%, CPS 10%, CRM 6%가 뒤를 이었습니다. 고객은 홈이 아니라 서로 다른 유입 맥락에서 여정을 시작했습니다.

TRAFFIC ≠ INTENT1.08%

전환 효율은 2월이 가장 높았습니다.

방문 규모는 4~5월이 컸지만 구매전환율은 2월이 가장 높았습니다. 트래픽과 구매 의도는 함께 봐야 했습니다.

START POINT5 / 6

Mobile은 메인이 시작 1위였습니다.

Mobile은 6개월 중 5개월 메인이 1위였고, PC는 6개월 모두 상품이 시작 1위였습니다. 기기마다 기대하는 시작 역할이 달랐습니다.

SEARCH9.34%

검색 비중은 오히려 높아졌습니다.

2026년 상반기 검색 시도는 2,670,682회였습니다. 검색은 보조 기능이 아니라 구매 후보를 구체화하는 핵심 행동이었습니다.

HOME49.6%

홈에서는 주요서비스로 가장 많이 이동했습니다.

퀵메뉴 계열도 33.8%였습니다. 많은 콘텐츠를 소비하기보다 원하는 목적지로 빠르게 가는 기능을 더 많이 사용했습니다.

LANDING → ACTION52.2%

기획전 진입 후 바로 종료했습니다.

PDP 이용은 10.09M에서 10.87M로 늘었지만 장바구니와 구매는 감소했습니다. 관심이 구매 확신으로 이어지는 구간이 약했습니다.

01 / ENTRY CONTEXT

시작점은 하나가 아니었습니다.

AD·Direct·CPS·CRM으로 서로 다른 맥락을 가진 고객이 들어왔고 Mobile과 PC의 시작 화면도 달랐습니다.

02 / REPEATED EXPLORATION

구매 후보는 반복 탐색에서 만들어졌습니다.

검색·카테고리·목록을 오가며 후보를 만들고 가격·혜택·설치 조건을 비교했습니다.

03 / CONFIDENCE GAP

관심은 유지됐지만 다음 행동은 약해졌습니다.

기획전 종료 52.2%, PDP 이용 증가와 장바구니·구매 감소가 같은 단절을 보여줬습니다.

홈, 검색, PDP를 따로 고치는 대신
전체 구매 흐름을 하나의 설계 문제로 봤습니다.

고객이 앞 단계에서 만든 관심·혜택·비교 기준이 다음 화면에서도 이어져야 했습니다. 화면의 역할을 ‘무엇을 보여줄지’보다 ‘다음 판단을 어디까지 끝낼지’로 다시 정의했습니다.

04 / UX STRATEGY

잘하는 것은 더 강하게,
아쉬운 것은 여정에서 줄였습니다.

고객이 하이마트에서 기대하는 전문성·매장 경험·설치와 A/S의 신뢰는 온라인 안으로 가져오고, 검색·비교·주문·설치 과정에서 반복되는 불확실성은 다음 화면으로 넘기지 않도록 설계 기준을 정했습니다.

05 / TRANSPARENCY

약속과 상태를
눈에 보이게

총액·혜택·설치 가능일·진행 상태를 명확히 보여줘 다시 문의하지 않아도 현재 상태를 이해하게 합니다.

05 / JOURNEY ROLE

그리고 각 여정의 역할을
다시 정의했습니다.

앞서 확인한 단절을 기준으로 홈부터 구매 이후 관리까지 각 여정이 다음 판단을 어디까지 완료해야 하는지 정의하고, 그 역할을 프로토타입의 정보 우선순위와 연결 기준으로 사용했습니다.

HOME

홈은 보여주는 곳이 아닌 원하는 곳으로 보내주는 곳이어야 한다

최근 관심 상품·혜택·서비스를 기억하고 검색·카테고리·주요 서비스로 빠르게 이어줍니다.

SUBHOME / CATEGORY

선택한 카테고리 안에서는 고민의 시간을 줄여야 한다

많이 찾는 상품과 선택 기준을 먼저 보여줘 카테고리 안에서 비교와 선택을 빠르게 만듭니다.

SEARCH

검색은 불확실성을 확신으로 바꿔줘야 한다

정확한 모델명을 몰라도 모호한 니즈를 구체적인 상품 후보로 바꾸는 탐색을 지원합니다.

SRP / PLP

검색 결과는 단순 상품 목록이 아니라 비교를 끝내는 화면이어야 한다

가격·혜택·브랜드·배송·설치·리뷰·스펙을 같은 기준으로 비교해 구매 후보를 빠르게 압축합니다.

PDP

상세페이지는 설명하는 화면이 아니라 결정을 끝내는 화면이어야 한다

가격과 설치 가능성, 리뷰, 혜택, 매장 확인과 케어 정보를 함께 보여 구매 결정을 완료하도록 돕습니다.

CART / PAY

장바구니는 결제 직전의 마지막 확신을 줘야 한다

가격·혜택·옵션·설치 조건과 최종 금액을 한 번에 재확인해 결제 직전의 불확실성을 줄입니다.

INSTALL

설치 조율에서는 결제 이후의 불안을 일정 확정으로 바꿔야 한다

설치 일정과 가능 여부, 폐가전 회수 정보를 명확히 안내해 결제 이후의 불안을 줄입니다.

MY / CARE

마이페이지에서는 구매 이후에도 관리받고 있다는 느낌을 줘야 한다

안심케어·수리·이전설치·정기점검을 상품 이력과 연결해 구매 이후의 관리 경험을 이어갑니다.
