Featured case / AIMMO

Building a system without stopping the product.

Role
Head of Design
Focus
Design System
Scope
Product · Team · Process
Period
2022—2024
01 / Context

The challenge was not creating components. It was deciding where to start.

여러 라이브 제품이 동시에 운영되고 있었고 제품마다 서로 다른 UX 패턴이 존재했습니다. 전체 서비스를 한 번에 교체할 수 없는 상황에서, 가장 많이 사용되는 컴포넌트부터 우선순위를 정하고 실제 제품 안에서 점진적으로 적용하는 방식을 선택했습니다.

02 / Decision

Start with what people use most, then turn it into a shared language.

컴포넌트, 디자인 에셋, 토큰과 라이브러리를 단계적으로 정리했습니다. 핵심은 화면을 동일하게 만드는 것이 아니라 제품별 중복 판단과 반복 커뮤니케이션을 줄이는 것이었습니다.

-72%GUI production time
-38%Front-end development time
-63%Communication time
+45%Time spent considering UX
03 / AI inflection

AIMMO became the point where AI usage accelerated dramatically.

이 시기부터 AI는 단순히 아이디어를 얻기 위한 도구를 넘어 리서치, 탐색, 구조화, 프로토타이핑, 빠른 검증을 이어주는 실무 방식으로 확장되었습니다. 이후의 디자인 리딩에서도 AI를 이용해 문서보다 먼저 경험을 만들어보고, 실제 결과를 기준으로 유관부서와 의사결정하는 방식이 강화되었습니다.
