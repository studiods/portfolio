01

리브랜딩은 되어 있었지만,
브랜드는 실제 접점에서 제대로 작동하지 않았습니다.

로고와 기본 그래픽은 있었지만 제품·부서·채널마다 활용 방식이 달랐고, 어디까지 어떻게 써야 하는지 기준도 없었습니다.

01.1 / BRAND REALITY

브랜드 자산은 있었지만,
서비스와 홍보 환경에서는 제한적으로만 쓰이고 있었습니다.

외주 리브랜딩 이후 로고타입과 기본 모티브는 정의됐지만 노출 환경을 고려한 활용 규칙과 예시가 부족해 시인성과 일관성이 함께 떨어졌습니다.

01 / ASSET

리브랜딩 결과물은 존재했습니다.

로고와 기본 그래픽 모티브가 이미 정의되어 있었습니다.

02 / VISIBILITY

실제 노출 환경에서는 힘이 약했습니다.

화면·공간·인쇄물마다 크기와 컬러의 시인성이 충분하지 않았습니다.

03 / GUIDE

어떻게 확장해야 하는지 기준이 없었습니다.

브랜딩 요소를 활용할 가이드와 예시가 없어 사용 범위가 제한적이었습니다.

04 / CONSISTENCY

부서와 제품마다 서로 다르게 사용했습니다.

같은 브랜드가 접점마다 다른 인상으로 보이는 상황이 반복됐습니다.

01.3 / REFRAME

그래서 새로운 로고를 만드는 대신,
기존 브랜드를 더 많이, 더 일관되게 쓰는 방법을 설계했습니다.

이미 만들어진 핵심 자산을 버리지 않고 형태적 특징을 모듈로 분해해 다양한 접점에서 다시 조합할 수 있는 그래픽 언어로 확장했습니다.

02

에이모다움을 먼저 정의하고,
로고의 형태를 재조합 가능한 모듈로 바꿨습니다.

내부 구성원 인터뷰, 리서치와 시장 조사를 통해 브랜드의 특성을 정리한 뒤 기존 형태를 유지하면서도 확장 가능한 조형 규칙을 만들었습니다.

02.1 / FIND THE CHARACTER

그래픽을 그리기 전에,
에이모가 어떤 회사로 기억되어야 하는지부터 확인했습니다.

내부 구성원 인터뷰와 리서치, 시장 조사를 통해 기술 회사의 전문성을 유지하면서도 더 대담하고 가볍고 유연한 인상을 만들고자 했습니다.

BE BOLD

기술과 제품의 자신감을 명확한 형태와 대비로 보여줍니다.

BE LIGHT

무겁고 경직된 B2B 인상보다 빠르고 유연한 경험을 만듭니다.

BE UNUSUAL

흔한 AI 기업의 표현에서 벗어나 기억되는 조형 언어를 만듭니다.

점·캡슐·사선 바처럼 이미 에이모의 형태 안에 있던 요소를 반복 가능한 최소 단위로 정의했습니다.

형태의 문법은 같게 유지하되 조합·밀도·방향을 바꿔 제품군과 커뮤니케이션 목적에 맞게 변주할 수 있게 했습니다.

03

그래픽 모티브를 화면 안에 두지 않고,
브랜드가 만나는 모든 접점으로 확장했습니다.

홈페이지, 제품 커뮤니케이션, CES 부스와 인쇄물까지 하나의 디자인 컨셉으로 연결해 브랜드 경험의 밀도를 높였습니다.

03.1 / EXHIBITION EXPERIENCE

해외 전시에서는 제품 하나보다,
브랜드 전체가 한 번에 기억되도록 만들었습니다.

부스·사인·그래픽·제품 소개물이 같은 모티브를 사용하도록 연결해 멀리서도 에이모의 인상이 먼저 보이게 했습니다.

01 / EXHIBITION

그래픽 모티브를 공간 경험의 기준으로 확장했습니다.

CES 등 해외 전시에서 부스와 제품 메시지가 하나의 브랜드로 읽히도록 전체 디자인 컨셉을 다시 정리했습니다.

02 / APPLICATION

같은 모듈이 인쇄물과 디지털 화면에서도 다른 밀도로 작동하게 했습니다.

브로셔·프로덕트 소개·사인·웹 화면마다 같은 조형 언어를 유지하면서 목적에 맞게 조합했습니다.

SOURCE - 기존 포트폴리오 25-26p / 전시 부스·프로덕트·인쇄물·굿즈 적용 사례
03.2 / DIGITAL EXPERIENCE

홈페이지도 정보를 나열하는 B2B 사이트가 아니라,
브랜드의 수준을 먼저 보여주는 경험으로 다시 잡았습니다.

그래픽 모티브의 움직임과 대비를 디지털에 적용해 제품 설명 이전에 에이모의 기술력과 태도를 느낄 수 있도록 방향을 잡았습니다.

03.3 / VISUAL SYSTEM

한 가지 레이아웃에 가두지 않고,
이미지가 중심이 되는 큰 화면과 정보형 레이아웃을 함께 쓸 수 있게 구성했습니다.

향후 실제 전시·홈페이지·굿즈 이미지를 추가하기 쉽도록 리유즈 프로젝트의 대형 갤러리 문법을 가져와 미디어 중심 구조로 설계했습니다.

EXHIBITION / BOOTH IMAGE

공간과 전시 이미지를 화면 가득 보여주는 레이아웃

부스 전경·사인·현장 적용 사진처럼 공간 스케일을 보여주는 자료를 위한 영역입니다.

WEB / PRODUCT IMAGE

디지털 화면과 제품 커뮤니케이션을 비교하는 레이아웃

홈페이지·제품 소개 화면·그래픽 적용 전후 이미지를 추가할 수 있도록 구성했습니다.

PRINT / GRAPHIC IMAGE

그래픽 시스템의 변주를 연속으로 보여주는 레이아웃

포스터·브로셔·패턴·인쇄물처럼 모듈이 어떻게 확장되는지 보여주는 영역입니다.

04

브랜드 표현을 바꾸자,
외부의 평가와 내부의 사용 방식도 함께 달라졌습니다.

그래픽 모티브는 전시와 세일즈에서 포지셔닝을 높이고, 내부 행사·교육·커뮤니케이션에서는 구성원들이 브랜드를 직접 사용하는 도구가 됐습니다.

04.1 / BUSINESS IMPACT

단가 경쟁만으로 설명하던 자리에서,
브랜드의 수준까지 함께 평가받기 시작했습니다.

새로운 전시·브랜드 경험은 해외 현장에서 긍정적인 반응으로 이어졌고, 계약 성과와 브랜드 인지도 모두 이전보다 크게 높아졌습니다.

3×+

해외 전시 이후 계약 체결

개선된 브랜드 경험을 적용한 이후 실제 계약 체결이 기존 대비 3배 이상으로 이어졌습니다.

POSITIONING

가격이 아니라 브랜드와 제품의 수준으로 설명할 수 있게 됐습니다.

좋은 제품이 낮은 가격대 브랜드와 같은 선상에서만 비교되던 한계를 줄였습니다.

RECOGNITION

전시와 세일즈 접점에서 브랜드 인지도를 높였습니다.

일관된 그래픽 언어와 공간 경험이 에이모를 기억하게 만드는 장치가 됐습니다.

04.2 / INTERNAL BRANDING

밖에서 보이는 브랜드만 바꾸지 않고,
구성원이 매일 사용하는 브랜드까지 확장했습니다.

웰컴킷·공용 문서·행사 배너·브로셔·굿즈·내부 교육과 파트너 교육까지 같은 그래픽 시스템을 적용했습니다.

01 / EVERYDAY

웰컴킷 · 공용 문서 · 사내 커뮤니케이션

작은 접점부터 브랜드 변화가 체감되도록 적용했습니다.

02 / EVENT

회사 행사 · 내부 교육 · 파트너 교육

행사와 교육에서도 하나의 브랜드 톤을 유지해 구성원의 호응을 높였습니다.

03 / GOODS

배너 · 브로셔 · 티셔츠 · 굿즈

구성원이 직접 사용하고 입는 영역까지 그래픽 언어를 확장했습니다.

INTERNAL BRANDING

브랜드를 보는 것에서 직접 사용하는 것으로 바꿨습니다.

포트폴리오 28-30p의 웰컴킷·행사물·굿즈 적용처럼 내부 구성원이 브랜드를 일상에서 반복 경험하도록 확장했습니다.

SOURCE - 기존 포트폴리오 28-30p / Internal Branding & Official Site Renewal
