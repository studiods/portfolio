01 / REFRAME

처음에는,
만보계를 만드는 프로젝트였습니다.

캐시슬라이드 사용자의 걸음 수를 측정하고, 걷는 만큼 보상을 제공하는 만보기 서비스에서 시작했습니다.

01.1 / QUESTION

하지만 숫자와 보상만으로는,
내일도 다시 사용할 이유가 부족했습니다.

START

얼마나 걸었는가?

걸음 수, 거리, 시간, 칼로리처럼 하루의 활동 결과를 정확하게 보여주는 전형적인 만보기 경험입니다.

SHIFT

어떻게 하면 계속 걷게 만들 수 있을까?

측정 자체보다 사용자가 다시 돌아오고, 걷는 행동을 반복하게 만드는 이유를 제품의 중심으로 옮겼습니다.

PRODUCT REFRAME

측정하는 서비스에서,
다시 돌아오게 만드는 서비스로.

02 / EXPERIENCE STRATEGY

숫자를 확인하는 경험보다,
사용자와 관계를 만드는 경험에 집중했습니다.

기록을 없애는 것이 아니라, 기록을 행동을 지속시키는 재료로 사용했습니다. 걷기·상호작용·재방문의 세 축으로 경험을 다시 구성했습니다.

01 / WALK

걷는 행동은 단순하게

오늘의 걸음과 활동 정보를 별도의 학습 없이 빠르게 확인할 수 있도록 기본 경험을 명확하게 유지했습니다.

02 / INTERACT

숫자 대신 캐릭터와 반응하게

메이트를 선택하고 행동에 따라 서비스가 반응하도록 만들어 Utility 이상의 정서적 접점을 만들었습니다.

03 / RETURN

한 번의 보상보다 다시 들어올 이유를

출석, 추가 보상, 미션 같은 반복 접점을 통해 오늘의 행동이 다음 방문으로 자연스럽게 이어지게 했습니다.

05 / OUTCOME

사용자를 걷게 만드는 것에서,

출시 후 지속적인 모니터링과 개선을 이어갔고, 기존 포트폴리오 기록 기준 서비스 이용 규모도 빠르게 성장했습니다.
