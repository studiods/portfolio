01 / REFRAME

처음에는,
만보계를 만드는 프로젝트였습니다.

캐시슬라이드의 리워드 경험과 만보기 기능을 결합해, 걷는 행동 자체에 혜택을 주는 서비스에서 시작했습니다.

01.1 / BUSINESS CONTEXT

이미 큰 서비스였던 캐시슬라이드에,
새로운 일상 접점이 필요했습니다.

2018 MARKET CONTEXT

가입자 2,000만 명에 근접한 캐시슬라이드

당시 캐시슬라이드는 성숙기에 접어든 대표 리워드 서비스였습니다. NBT는 광고 확인을 넘어 사용자의 일상 행동 자체로 혜택 경험을 확장하는 후속 서비스를 전개하고 있었습니다.

NBT MISSION

‘일상의 낙’을 반복 행동으로 확장

NBT는 스텝업을 사람들이 매일 반복하는 활동에 혜택을 더하는 확장 서비스로 소개했습니다. 단순히 걸음을 세는 것보다 매일 다시 사용할 이유를 만드는 것이 더 중요한 과제가 됐습니다.

01.2 / QUESTION

그래서 질문을,
걸음 수에서 반복 행동으로 바꿨습니다.

START

얼마나 걸었는가?

걸음 수·거리·칼로리·시간을 보여주고 걷는 만큼 캐시를 제공하는 전형적인 만보기형 리워드 경험에서 출발했습니다.

SHIFT

어떻게 하면 내일도 걷게 만들 수 있을까?

측정 자체보다 목표, 보상, 메이트와의 상호작용을 통해 사용자가 다시 돌아오고 걷는 행동을 반복하게 만드는 구조로 제품의 중심을 옮겼습니다.

PRODUCT REFRAME

측정하는 서비스에서,
다시 돌아오게 만드는 서비스로.

02 / EXPERIENCE STRATEGY

걷기를 기록하는 기능을,
매일 반복되는 리워드 경험으로 바꿨습니다.

공개 당시 서비스 구조를 기준으로 보면 스텝업은 걸음 측정, 목표, 캐시, 메이트, 재방문을 하나의 반복 경험으로 연결했습니다.

02.1 / REWARD MECHANISM

행동과 보상 사이의 거리를,
최대한 짧게 만들었습니다.

50보

걷는 즉시 적립되는 짧은 피드백

2018년 공개 정책 기준, 50보마다 1캐시를 지급해 행동과 보상이 멀어지지 않게 했습니다.

1,000C

개인 목표 달성에 추가 보상

사용자가 목표 걸음 수를 설정하고 달성하면 최대 1,000캐시를 추가로 받을 수 있었습니다.

6,000C

한 달의 걷기를 이해 가능한 가치로

매일 1만 보를 걸을 경우 한 달 약 6,000캐시라는 구체적인 누적 가치를 제시했습니다.

60+

쌓인 캐시를 실제 혜택으로 연결

초기 공개 기준 카페·영화관 등 60여 제휴처 모바일 상품권과 현금 전환으로 보상의 실질성을 높였습니다.

02.2 / EXPERIENCE

숫자만 보여주는 대신,
걷는 이유를 여러 층으로 만들었습니다.

WALK / CHECK

오늘의 상태는 가장 단순하게

오늘 걸음 수와 거리·시간·칼로리, 적립 상태를 한 화면에서 빠르게 확인하도록 기본 Utility 경험은 최대한 명확하게 유지했습니다.

MATE / INTERACT

캐릭터를 걷기 경험의 메이트로

캐릭터를 장식 요소로 두지 않고 응원과 추가 적립을 제공하는 산책 메이트로 사용해 정서적 동기와 기능적 보상을 연결했습니다.

MISSION

한 번의 보상 다음에 새로운 목표를

출석, 목표 달성, 미션 등 서로 다른 보상 접점을 배치해 한 번의 적립으로 행동이 끝나지 않고 다음 행동으로 이어지게 했습니다.

RETURN

오늘의 기록이 내일의 방문으로

오늘의 성취와 누적 기록을 확인하고 다시 목표를 세우는 구조를 통해 만보기 사용을 일회성 확인이 아닌 일상의 반복 경험으로 전환했습니다.

04 / ITERATION

출시를 끝으로 보지 않고,
사용자의 반응을 계속 제품에 돌려 넣었습니다.

UX 설계·기획과 GUI, 개발 Follow-up에서 끝내지 않고 출시 후 UT·FGI와 지속적인 모니터링으로 기능과 경험을 점진적으로 개선했습니다.

02

DESIGN

UX 구조와 GUI를 직접 설계하고 주요 인터랙션과 보상 흐름을 연결했습니다.

03

BUILD
