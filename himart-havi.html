01

가전 구매의 어려움은 질문보다,
조건을 정리하기 어렵다는 데 있었습니다.

사용자는 “냉장고 추천해줘”라고 말할 수 있지만 실제 선택에는 예산, 공간, 가족 구성, 사용 습관, 설치 조건처럼 더 많은 맥락이 필요합니다. HAVI의 첫 역할을 답변 생성이 아니라 사용자의 조건을 함께 정리하는 일로 정의했습니다.

01.1 / USER CONTEXT

사용자가 처음부터 말하기 어려운 조건을
대화 안에서 하나씩 구체화했습니다.

사용자가 정리해야 하는 조건

예산설치 공간가족 구성사용 습관선호 브랜드필수 기능크기·용량배송·설치 조건기존 가전 처리

하이마트가 연결할 수 있는 자산

가전 전문 상담다브랜드 비교매장 실물 확인PDP 정보배송·설치폐가전 회수안심케어A/S구매 이후 관리
01.2 / PROBLEM REFRAME

그래서 ‘검색을 대신하는 AI’보다,
‘판단을 이어주는 컨설턴트’가 필요했습니다.

CHATBOT

질문에 답하는 기능

사용자의 질문을 그대로 받아 제품이나 정보를 알려주지만, 질문 자체가 모호하면 선택 기준도 그대로 모호하게 남습니다.

HAVI

조건을 정리하고 다음 행동을 연결

막연한 질문을 생활 조건으로 구체화하고 후보를 줄인 뒤 비교·PDP·상담·설치까지 같은 맥락을 이어갑니다.

결론

HAVI의 핵심은 더 많은 답을 만드는 것이 아니라, 사용자가 스스로 선택할 수 있도록 구매 판단의 순서를 정리해주는 것이었습니다.

02

캐릭터의 외형보다 먼저,
어떤 태도로 도와야 하는지 정의했습니다.

AI Agent는 말투와 캐릭터가 눈에 띄기 쉽지만, 사용자가 믿고 구매 판단을 맡기려면 먼저 어떤 질문을 하고, 얼마나 설명하고, 언제 상품을 추천하고, 언제 사람에게 넘겨야 하는지가 명확해야 했습니다.

02.1 / AGENT PRINCIPLES

HAVI가 지켜야 할 여섯 가지
행동 원칙을 먼저 만들었습니다.

01 / ASK

먼저 묻고 이해합니다.

상품부터 추천하지 않고 예산·공간·사용 조건처럼 선택에 필요한 맥락을 먼저 확인합니다.

02 / NARROW

선택지를 줄여줍니다.

많은 상품을 나열하기보다 조건과 우선순위에 맞지 않는 후보를 먼저 덜어냅니다.

03 / EXPLAIN

추천 이유를 설명합니다.

AI가 고른 결과가 아니라 어떤 조건 때문에 이 상품이 맞는지 사용자가 이해하게 합니다.

04 / COMPARE

스펙을 생활 언어로 바꿉니다.

숫자 차이를 나열하기보다 실제 사용에서 어떤 차이가 생기는지 비교합니다.

05 / CONNECT

필요하면 사람에게 넘깁니다.

설치 제약이나 복잡한 상담이 필요하면 매장·전문 상담으로 자연스럽게 연결합니다.

06 / CONTINUE

구매 이후까지 기억합니다.

구매로 대화를 끝내지 않고 설치·회수·케어와 A/S까지 같은 맥락을 이어갑니다.

02.2 / ROLE

AI가 잘하는 것과,
하이마트가 잘하는 것을 연결했습니다.

AI

조건 정리·후보 축소

대화 맥락을 구조화하고 조건에 맞는 후보와 비교 기준을 빠르게 정리합니다.

CONTEXT · FILTER · COMPARE
HIMART

전문성·실물·서비스

다브랜드 상품 정보, 매장 실물 확인, 전문 상담, 배송·설치·케어라는 실제 자산을 제공합니다.

EXPERTISE · STORE · SERVICE
HAVI

둘을 하나의 경험으로

AI의 정리 능력과 하이마트의 오프라인·서비스 자산을 구매 맥락 안에서 이어주는 역할을 합니다.

AGENT · O2O · LIFECYCLE
03

그리고 HAVI가 개입하는 순간을,
전체 구매 여정 안에서 정의했습니다.

검색창 하나에 갇힌 Agent가 아니라 사용자의 조건을 파악한 뒤 후보 축소, 비교, PDP, 매장과 상담, 구매·설치·케어까지 필요한 순간마다 역할이 달라지는 구조를 설계했습니다.

03.1 / AGENT JOURNEY

대화의 시작부터 구매 이후까지,
여덟 단계로 연결했습니다.

01 / UNDERSTAND

막연한 질문 이해

사용자가 말한 목적과 상황에서 필요한 조건을 먼저 찾습니다.

02 / CLARIFY

조건 구체화

예산·공간·가족 구성·설치 제약과 우선순위를 함께 정리합니다.

03 / NARROW

후보 축소

조건과 맞지 않는 상품을 덜어내고 실제 비교할 수 있는 수로 줄입니다.

04 / COMPARE

생활 기준 비교

스펙 차이를 실제 사용 경험과 연결해 선택의 이유를 설명합니다.

05 / PDP

상세 확인

선택한 후보의 PDP에서 필요한 근거와 혜택, 설치 정보를 이어서 확인합니다.

06 / CONNECT

매장·상담 연결

실물 확인이나 전문 상담이 필요하면 대화 맥락을 유지한 채 다음 접점으로 넘깁니다.

07 / INSTALL

구매·설치 지원

설치 조건, 일정, 기존 가전 회수처럼 구매 이후의 실행까지 연결합니다.

08 / CARE

케어·A/S

구매가 끝난 뒤에도 관리와 케어, A/S를 같은 고객 맥락에서 이어갑니다.

03.2 / TOUCHPOINT

같은 Agent라도,
화면마다 해야 할 역할은 달랐습니다.

HOME

막연한 목적에서 시작

“혼수가전 보고 있어요”처럼 정리되지 않은 요구를 가볍게 받아 조건을 확인합니다.

SEARCH / SRP

탐색을 좁혀줍니다.

검색어를 반복하게 하지 않고 이미 파악한 조건으로 결과와 필터를 정리합니다.

PDP

판단 근거를 보완합니다.

현재 상품이 사용자 조건에 왜 맞고 무엇을 더 확인해야 하는지 맥락에 맞춰 설명합니다.

STORE

실물 확인으로 넘깁니다.

온라인에서 해결하기 어려운 체감과 상담은 가까운 매장·전문 상담으로 이어줍니다.

INSTALL

구매 이후 제약을 확인

문 폭, 설치 공간, 일정과 회수처럼 실제 설치에 필요한 조건을 이어서 챙깁니다.

CARE

관계가 끊기지 않게

구매 제품과 이전 대화 맥락을 바탕으로 관리, 케어와 A/S까지 연결합니다.

결론

HAVI는 하나의 화면에 붙는 AI가 아니라, 하이마트의 구매·상담·설치·케어를 같은 고객 맥락으로 연결하는 경험으로 설계했습니다.

04

실제 HAVI의 캐릭터와 Agent UX로 연결합니다.

역할·성격·추천 방식과 여정 개입 원칙이 실제 대화와 화면에서 어떻게 드러나는지 보여주는 구간입니다. 캐릭터 자체를 크게 자랑하기보다 조건 파악 → 후보 축소 → 비교 → PDP → 상담·설치·케어로 이어지는 실제 UX를 중심으로 구성합니다.
