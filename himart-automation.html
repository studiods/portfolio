01

AI를 쓰기 전에,
어떤 일을 사람이 계속 해야 하는지부터 나눴습니다.

디자인 업무 전체를 자동화하려고 하지 않았습니다. 반복되는 제작·변형·정리·탐색은 규칙을 만들 수 있지만, 사용자 맥락을 이해하고 정보의 우선순위를 정하고 결과의 품질을 판단하는 일은 여전히 디자이너의 책임이라고 봤습니다.

01.1 / REPEAT VS JUDGMENT

자동화할 일과,
남겨야 할 판단을 분리했습니다.

AUTOMATE

반복되는 제작과 탐색

배너 사이즈 변형, 반복 카피 구성, 이미지 배경·연출 탐색, 템플릿 기반 시안, 레퍼런스 수집과 분류처럼 규칙과 패턴이 있는 일을 우선 자동화 대상으로 봤습니다.

KEEP HUMAN

맥락과 품질을 판단하는 일

어떤 문제를 풀 것인지, 무엇을 먼저 보여줄지, 브랜드와 서비스에 맞는지, 어떤 안을 최종 선택할지는 디자이너가 직접 판단하도록 남겼습니다.

01.2 / TARGET

가장 반복이 많고,
효과를 바로 확인할 수 있는 곳부터 시작했습니다.

01 / BANNER

프로모션 배너

사이즈와 노출 위치에 따라 반복되는 변형 작업을 규칙화합니다.

02 / COPY

메시지 구조

프로모션 목적과 상품 정보를 입력하면 초안과 조합을 빠르게 탐색합니다.

03 / IMAGE

이미지 연출

Flux 등 이미지 생성 AI로 상품 연출, 배경, 조명과 비율별 변형안을 빠르게 만듭니다.

04 / RESEARCH

레퍼런스 분류

국내외 사례와 메시지 구조를 AI로 비교·분류해 초기 탐색 시간을 줄입니다.

05 / PROTOTYPE

동작 검증

정적 화면만으로 설명하기 어려운 인터랙션을 AI 코딩으로 빠르게 구현합니다.

06 / ITERATION

빠른 수정

리뷰 피드백을 코드·프롬프트·컴포넌트 수정으로 빠르게 다시 반영합니다.

결론

AI의 역할은 디자이너를 대신하는 것이 아니라, 반복에 쓰이던 시간을 판단과 검증으로 돌려주는 것이라고 정의했습니다.

02

반복 제작을,
입력과 규칙으로 다시 설계했습니다.

프로모션·광고 제작에서 반복되는 입력과 제작 과정을 Script / Maker 형태로 정리하고, 생성형 AI를 초기 비주얼 탐색과 변형 제작에 연결했습니다. 중요한 것은 AI 이미지가 아니라 팀이 재사용할 수 있는 제작 흐름을 만드는 것이었습니다.

02.1 / SCRIPT · MAKER

요청을 받는 순간부터,
결과를 검토하는 단계까지 연결했습니다.

01 / INPUT

목적·상품·채널 입력

프로모션 목적과 핵심 상품, 노출 위치와 필요한 비율을 구조화합니다.

02 / SCRIPT

메시지 초안 생성

타이틀과 핵심 문구의 조합을 빠르게 만들고 편집 가능한 초안으로 둡니다.

03 / VISUAL

연출 방향 탐색

Flux 등 생성형 AI로 배경·조명·상품 연출의 여러 방향을 빠르게 비교합니다.

04 / MAKER

레이아웃 변형

반복되는 배너 비율과 구성 규칙을 이용해 제작 속도를 높입니다.

05 / DESIGN

디자이너 조정

정보 우선순위와 브랜드 맥락, 실제 상품 표현을 사람이 다시 정리합니다.

06 / REVIEW

품질 검수

AI 특유의 오류와 과장, 메시지 적합성을 검토하고 최종 결과를 결정합니다.

07 / REUSE

규칙 재사용

다음 프로모션에서도 쓸 수 있도록 프롬프트와 제작 규칙을 축적합니다.

초기에는 프로모션·배너와 이미지 제작에서 시작했지만, 이후 UX·브랜드 리서치, 실제 동작 가능한 프로토타입, 디자인 시스템 사례 분석과 운영 디자인까지 활용 범위를 넓혔습니다.

03.1 / EXPANSION

AI를 어디에 썼는지가 아니라,
각 단계에서 무엇을 줄였는지 보여줍니다.

01 / RESEARCH

자료 수집과 분류

경쟁사 화면, 사용자 리뷰와 VOC성 의견을 모아 공통 패턴과 가설을 빠르게 구조화합니다.

02 / STRUCTURE

정보 구조 초안

고객 시나리오와 이탈 요인, 화면 정보 우선순위를 초안화해 설계의 출발을 빠르게 만듭니다.

03 / PROTOTYPE

동작 가능한 목업

Figma Make, ChatGPT Codex, Gemini Canvas 같은 AI 코딩 도구로 인터랙션을 빠르게 구현합니다.

04 / VISUAL

이미지·비주얼 탐색

Flux 등 이미지 생성 AI로 상품 연출과 배경, 프로모션 무드를 빠르게 비교합니다.

05 / SYSTEM

컴포넌트 사례 분석

국내외 디자인 시스템을 분류하고 상태값·네이밍·접근성 기준의 초안을 도출합니다.

06 / OPERATION

운영·예외 대응

단발성 기능과 정책 변경에서도 유사 사례, 예외 케이스와 안내 문구를 빠르게 정리합니다.

결론

AI를 많이 쓰는 팀보다, AI로 줄일 일과 사람이 더 깊게 볼 일을 구분할 수 있는 팀을 만드는 것이 중요했습니다.
